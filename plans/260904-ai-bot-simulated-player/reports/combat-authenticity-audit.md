## A. HorseLimit semantics (THIS server) — CORRECTED 2026-09-04

Verified from `settings/skills.txt` + live bug (Loi Dong Cuu Thien on horse):

| HorseLimit | Count | Meaning |
|------------|-------|---------|
| **0** | 989 | **May cast while mounted** (no restriction) |
| **>=1** | 235 | **MUST dismount** before cast |

Example: skill **375 Loi Dong Cuu Thien** has `HorseLimit=1` → foot only.

Earlier mistake treated HL>=1 as horse-OK (inverted). Fixed in `tools/gen_skill_meta.py` + regenerated `sim.skill_meta.lua`.

## B. AttackRadius

- Field `AttackRadius` in `skills.txt` is **pixels**.
- Tiles = `max(1, floor(AR/32))`; AR=0 → failsafe **2 tiles** (not 90px silent ranged).
- Cached once in `sim.skill_meta.lua` (generated by `tools/gen_skill_meta.py`).

## D. pendingSkill pipeline

`SimPickSkill` sets `tbNpc.pendingSkill` / `pendingSkillId` and **does not** flip `bua2Toggle` until `SimCommitSkillToggle` after cast.

`SimBotCastDist(tbNpc, skillId)` takes the same skill id used for horse + cast.

## E. PK root cause

Train/combat SimBots could become **NpcKind=4** (NPC / unattackable) via `SetFightState` / follow-parent paths, while still showing hostile camp colors.

Fix:

- `mode=="train"` / `tongkim` / `isAttackable==1` → **always `SetNpcKind(0)`**
- `isAttackable=1` default for train/TK
- `SimEnsureCombatAttackable` on breath/duel

Player can PK eligible combat bots in non-peace maps; peaceful bots still do not **initiate** aggro (`CHANCE_ATTACK_PLAYER=0` unless DoSat). DoSat restored at `TRAIN_DOSAT_PCT=8`.
